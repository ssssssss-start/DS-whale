# Runtime artwork

The base full-character reference was supplied by the project owner. Wave/lift textures derive from that reference. Four emotion source images were generated with the built-in image-generation tool and aligned/interpolated offline; `tools/build-emotions.swift` produces their runtime frames. These are project assets, not copied from the separate reference pet project.

This initial publication includes current runtime image sequences and emotion source images. Historic intermediate experiments and preview exports are excluded. No separate asset reuse license has been granted by this repository. Tail movement currently remains static to avoid deforming the full-body drawing.
