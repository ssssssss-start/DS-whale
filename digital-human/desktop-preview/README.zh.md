# 鲸鱼娘桌宠

详见仓库[安装说明](../../README.zh.md)。使用 `bash build.sh` 构建。当前运行素材位于 `assets/`。如需本地固定动作录音，可自行放置 `assets/sounds/welcome.mp3`、`poke-hum.mp3` 和 `headpat.mp3`；缺少录音时构建会跳过，动作仍可使用。

### 独立分层尾巴（v0.5.1）

尾巴已从原人物图分离为身体后方的独立图层。尾根固定在裙摆下，尾身小角度转动，尾尖延迟跟随；只变形尾巴自己的网格。周期 4.8 秒，尾身/尾尖角度约 1.8/1.4 度，尾尖相位延迟约 0.42 秒。可见尾巴沿用原画，内置 imagegen 只补隐藏尾根。头发、衣服和腿不参与尾巴摆动。Idle Motion 开关会平滑启停；挥手仍用已有完整人物帧，切入前短暂收回摆动，结束后渐进恢复。

`--export-tail /绝对输出目录` 可导出无语音预览及独立图层。检查覆盖尾根固定、尾尖连续、静止时原图像素重建。素材和提示词位于 `assets/tail-v1/`。此版替代此前静态尾巴修正。
