# 鲸鱼娘桌面动作原型

## 实时白色亮度（0.7.2 / build 25）

在 3D 模式下，点击动作按钮旁的 **◐**（或菜单中的 **White Brightness…**）。拖动 50–100% 滑块可压低明亮、低饱和度的白色，同时保持蓝发等饱和颜色不变。其他位置类似的白色高光也会受影响；这是按颜色识别，并非只针对布料的遮罩。调整实时生效，重启及切换 2D/3D 后仍然保留。满意后点 **Use as Reference** 保存参考标准，**Restore Reference** 恢复该标准。用户于 2026-10-23 确认的参考标准为 **94%**，同时作为新配置的默认值；已保存的个人调整优先。

## 3D 色彩修正（0.7.1 / build 24）

桌宠使用原贴图中已有的绘制明暗，不再叠加额外的金属高光，并在 SK3DNode 合成路径校正颜色输出。模型、贴图文件、骨骼和动作保持原版精度。此更新只需重开桌宠，不需要更新 Harness 插件。

关闭自动曝光适应，让实时角色保持参考图的亮度，再增加 +0.03 EV 的轻微提亮，保留白色布料的细节。

颜色验收使用 `--export-3d-composite <模型.glb> <输出目录>`，与真实桌宠采用相同的 SK3DNode → SpriteKit 路径，并检查浅色/深色背景、正侧背面与挥手；独立 SceneKit 渲染图不能代替桌宠画面验收。


## 原版精度 3D 模式（桌宠 0.7.0 / 插件 0.5.5）

右键桌宠，选择 **3D Character (Original Detail)**。此选项可切回 2D，选择会保存。原版模型的 1,383,928 个顶点、贴图与网格拓扑全部保留；没有减面。模型位于 `digital-human/3d/whale-full-v0.3/`，轻量 v0.2 不再作为当前成果。

3D 菜单提供转身、原地步行和摆尾。Agent 的 `whale_body` 根据桌宠实际能力提供 `turn`、`walk`、`tail_swish`，命令仍受会话归属、可见性、过期和回执约束。2D 不声明这些动作。3D 暂只声明 idle、greeting、poke、headpat 及这三个新增动作，旧四种表情尚未完成 3D 美术验收。通话的听／思考状态与头部动作关联；输出音量驱动简单口型，眨眼与口型仍为初稿。

运行中的旧应用需重开一次才能加载新二进制；新增 Agent 动作还需要通过 Harness 插件页安装 `releases/dsh-whale-voice-0.5.5.tgz`。构建和离线预览不会升级正在运行的插件或发起通话。原版高精度模型已通过本机 SceneKit 离线渲染；步行尚无脚部 IK，头发与裙摆尚无碰撞/物理模拟。


## Harness 启动与显示／隐藏入口（插件 0.5.4、桌宠 0.6.2/build 21）

进入 Harness 后自动启动鲸鱼娘一次。左下角 **DS Bot 上方**的按钮按实际状态切换：「隐藏鲸鱼娘」隐藏当前形象，「显示鲸鱼娘」恢复隐藏的形象，应用退出后则显示「启动鲸鱼娘」。两个入口都保持靠左排列。隐藏会停止播报并结束通话；显示或启动不会自动开麦或拨号。退出后不会被状态轮询重新拉起，需点击按钮重开。

同时更新桌宠和 `dsh-whale-voice-0.5.4.tgz`，运行中的旧桌宠需退出后重开一次。按钮等桌宠回传可见状态后才确认切换，通信失败会提示重试；旧桌宠不声明隐藏能力时，保留原来的启动／显示行为。首次从没有界面组件的旧插件升级，需在当前任务允许时重开 Harness，以刷新缺失客户端的缓存。

默认依次查找 `~/Applications/Whale Companion.app`、`/Applications/Whale Companion.app`、源码相邻的 `desktop-preview/Whale Companion.app` 和 `~/main/DeepSeek-Bot/digital-human/desktop-preview/Whale Companion.app`。Cordis 插件配置可设置绝对路径 `companionPath` 或 `autoStart: false`。仅支持 macOS；远程 Web 按钮控制 Harness 所在电脑。自动启动按插件宿主生命周期计，不是系统登录启动项。只使用公开侧栏插槽与已认证路由，不修改 Harness。

桌宠 **0.6.0/build 19** 支持桌面直连语音：双击形象开始通话，再次双击或点击红色电话挂断。独立状态条跟随形象，区分连接、聆听、识别、思考、说话和暂停，不随角色缩放而缩小。无需打开聊天页面；Harness 和插件 **0.5.0** 需在后台运行，并已配置聊天模型及准备好 Voice Input 识别器。桌宠需加载豆包配置、开启 Sound、授予麦克风权限。有绑定就使用绑定会话，否则创建并复用普通 Harness 语音会话，见[桌面通话说明](../桌面直连语音通话说明.md)。

桌宠 0.5.4/build 18 新增 Agent 身体控制，通过原有同用户语音 socket 接入。配合语音插件 0.4.4，仅绑定会话或当前鲸鱼娘通话拥有形象；`whale_body` 提供已有互动、表情及恢复待机动作。命令不播放固定台词、不停止 TTS、不替换正在进行的用户互动，两秒过期，并返回接受/忙碌/不可用回执；隐藏或设备不活跃时拒绝新动作。听觉与身体上下文见[插件说明](../harness-voice/README.zh.md)。需要重新构建并重开应用；单独构建不会重启运行中的桌宠。

macOS 原生透明桌面窗口，使用用户提供的幼态鲸鱼娘形象。挥手直接使用用户提供的五个完整形象，待机采用轻量二维形变，通过 `../harness-voice/` 插件接收已绑定会话的新直接回复，或带 `[whale]` 前缀的单轮回复，尚非完整 Live2D 模型。

## 运行与构建

双击 `Whale Companion.app` 即可运行；构建需要 Apple Command Line Tools：

```sh
bash build.sh
open "Whale Companion.app"
```

源码在 `main.swift`、`CharacterScene.swift`、`Interaction.swift`、`AudioFeedback.swift`；透明素材在 `assets/`，应用信息在 `Info.plist`。构建会打包已生成的贝壳 MP3，不需要语音服务在线。

## 第一版动作

| 操作 | 动作与声音 |
| --- | --- |
| 安静待机 | 随机眨眼、轻微呼吸、发梢与鲸尾局部缓慢摆动，默认不说话 |
| 单击角色 | 轻缩肩、偏头、短暂小跳，播放已试听的“嗯哼？”版本 |
| 头部长按 0.7 秒 | 眯眼微笑、轻微歪头、鲸尾摆动加快，播放摸头短语音 |
| 菜单 Say Hello | 抬手挥动、播放一次欢迎语音，然后回到待机 |

点击右上角 `⋯`、右键角色或顶部 Whale 菜单均可打开操作入口。Sound 立即静音，包括正在播放的声音；Idle Motion 关闭或恢复待机形变，仍可触发互动。

拖动超过 5 点会取消摸头。互动有 1.1 秒冷却；新互动停止上一段语音。互动状态持续到对应语音播放完，再自然恢复待机。隐藏时停止语音并暂停渲染。正常启动不自动说欢迎语，不读取 Harness 数据，也不设置开机自启。

v0.4.4 优先调整原有睁眼笑、闭眼笑的节奏，不新增表情素材：摸头用 0.5 秒进入、至少 2.6 秒完整停留、0.7 秒恢复，总长至少 3.8 秒；欢迎动作延长到至少 6 秒，抬手和闭眼笑的关键姿态有独立停留。连续互动先收好当前动作，再开始新动作，仅保留最后一个待执行互动，配套声音到动作真正开始时才播放。新回复正常出声，脸部不再直接重置；较早收到回复时，摸头笑脸保留到动作开始后 2.1 秒，再用 0.7 秒恢复。挥手受到打断时，在至少展示 2.6 秒后沿已有完整人物过渡帧用 1.6 秒收手。反复到来的回复不会延长恢复，也不会补播待执行的本地互动。眨眼仍保持短促：全程 0.28 秒，其中完全闭眼停留 0.06 秒，互动期间不叠加随机眨眼。当前仍使用两种表情，尚未补充新的眼皮形态。

v0.4.4 曾复用已有 0→1→2 插帧贴图，用两个眼部遮罩显示、不覆盖嘴巴，以替代两张脸透明叠加；但这两个遮罩仍切到了眉毛，已由下述 v0.4.5 方案替换。

v0.4.5 再次修正：两个小眼框仍切到了眉毛/眼皮，现替换为整体面部柔边过渡，边界放到发丝处，眼睛和嘴巴取自同一个原始过渡帧，避免局部矩形残留。抬手段延长到 1.6 秒，再用 0.8 秒到高处笑脸；放下手为 1.25 秒，整个欢迎动作至少 8.1 秒。用内置 imagegen 补了三张完整人物的中间姿态，再以离线 Apple Vision 光流和手掌位置约束生成 97 张透明抬手帧，运行时只播放图片。原始图和旧帧保留；新素材、实际提示词及来源见 [assets/lift-v3](assets/lift-v3/PROVENANCE.md)。手指细节在插帧中仍可能变软。

v0.4.6 修复上述中间姿态的横向滑动：生成器按原图读取位置，插帧前后分别约束脸部、围裙和脚底的横坐标；运行时改用 [assets/lift-v3](assets/lift-v3/PROVENANCE.md) 的 97 帧。上一版固定脚底中心与参考姿态不一致。独立图片检查测得，脚底中心在整段内的横向变化范围由 21.98 降到 0.82 个素材像素，相邻帧最大变化为 0.013 个素材像素；这不是桌面屏幕像素。构建会拒绝缺帧的对齐素材。编译 `tools/check-registration.swift`，传入桌宠目录和 `--check-lift-v3` 可检查实际图片序列，报告保存在 `previews/registration-v0.4.6.json`。

滚轮缩放，或菜单选择 50%–200%；默认窗口为 190 × 234 点。尺寸、位置、声音与待机动作偏好会保存。右上角 × 退出；再次启动会替换旧实例。

## 验证与边界

构建自动运行 `--self-test`，检查互动冷却、语音长度、互动替换、回到待机，以及五个完整姿态的播放顺序和时长适配。使用 `--demo` 参数可依次演示挥手、摸头、戳一戳；`--wave-demo` 只演示挥手，正常启动不会自动演示。

`FullBodyFrames.swift` 直接提取 `assets/wave-reference-full.png` 里的五个完整人物，移除黑底并统一裁剪范围，保留用户原图。挥手顺序为放手、抬手、眯眼挥手、睁眼、放下；每帧包含完整的肩膀、袖子、手掌和表情。保留五张原图作为关键姿态，用离线 RIFE 为每段生成 33 张完整透明帧。贴图提前加载，桌面以 60 fps 为目标播放，运行时不计算模型。关键姿态现有独立停留，最短欢迎周期中起始抬手为 0.5 秒；插帧仍可能使手指短暂变软。不叠加独立手臂或整体拉伸。

`--export-wave /绝对路径/输出目录` 使用桌宠相同的渲染逻辑导出无声 GIF、五张透明姿态图和渲染检查帧。此前生成的手臂素材和预览保留供参考，当前挥手已不再使用。

`--export-expressions /绝对路径/输出目录` 导出正常摸头、回复打断摸头、回复打断挥手三种无声预览；同时检查完整笑脸停留和打断时不跳脸。预览不读取语音配置、不调用云端 API。

尚无完整 Live2D 模型或精确对口型；语音识别现通过后台 Harness 公开接口接入。窗口保留透明背景、原有缩放与声音设置。

动态语音：菜单选择 **Connect Doubao Voice…**，在本机安全输入框填写火山引擎语音 API Key；凭证只留在内存，不需要本地语音服务。选择 **Test Voice (Uses API)** 试听一条固定短句，由你的 API 账户计费。绑定会话的新直接回复会自动朗读；其他会话可在消息前加 `[whale]`。完整说明见 [语音桥接](../harness-voice/README.zh.md)。音量驱动轻微说话动作，尚未实现音素嘴型同步。

主动交互首版已加入 **Do Not Disturb**（30 分钟/1 小时/持续）、**Proactive Voice**、**Companion Check-ins**、**Follow Next Conversation**、**Quiet Hours…** 与 **Recent Messages**。主动声音和陪伴默认关闭；免打扰只抑制主动事件，用户直接对话仍可回应，全局 Sound 静音优先。见 [实现与验证](../harness-voice/review/主动交互实现记录.md)。

## 豆包流式声音（桌宠 v0.4.3）

默认使用豆包官方语音合成 2.0，初始音色为甜美小源 2.0。**Doubao Voice** 还可切换撒娇学妹 2.0、温柔小雅 2.0、Vivi 2.0、小何 2.0（Xiaohe）、云舟 2.0（Yunzhou）、小天 2.0（Xiaotian），只保存音色选择。凭证不进入偏好、计时报告、IPC 或 Harness 插件；**Disconnect Voice** 停止声音并清除内存中的 Key。

v0.4.3 启动时读取 `Whale Companion.app` 旁边的 `voice-config.local.json`。当前目录已创建空模板，只需填写其中的 `doubao_api_key` 字符串；其他检出可复制 `voice-config.example.json` 为该文件名。本地配置已加入 Git 忽略，读取时限制为当前用户读写。配置放在应用包外，重建不会覆盖；移动应用时需一同移动配置。修改后可点 **Reload Voice Config…**，无需重开，加载本身不调用云端。配置缺失/Key 为空时仍可手动连接；配置错误只提示固定原因，不展示内容，也不替换当前有效 Key。**Connect Doubao Voice…** 仍只连接本次运行，不把输入写回配置。**Disconnect Voice** 仅清空内存，下一次启动或手动重新加载会再次读文件；若要关闭自动加载，清空或删除配置中的 Key。

v0.4.2 新增用户指定的四个音色，已对照[官方 TTS 2.0 音色列表](https://docs.volcengine.com/docs/DoubaoVoice/Tonelist-1?lang=zh)核实。Vivi、小何为女声，云舟、小天为男声。官方支持已确认；账号调用权限和实际音质仍需逐个试听。

填入 Key 后显示 `Doubao key set · select Test Voice`，此时尚未验证；成功合成后才显示 `Doubao connected · streaming ready`。接口失败会停止当前队列，不自动重试。使用固定官方 HTTPS 地址，拒绝重定向；网络会话不使用磁盘缓存或 Cookie。正常桌宠流程不再使用 DeepSeek 网页 token、本地贝壳服务或本地密码。

豆包适配使用官方双向 WebSocket：一轮回复建立一个连接和一个语音会话，用 TaskRequest 持续追加可朗读片段，同时接收音频；Harness 结束后发送 FinishSession，收到结束事件再收尾连接。插件仍使用清理后的完整片段及短句合并，没有逐原始 token 转发；不同回复轮次目前分别建连。预缓冲约 150 毫秒后起播，音量驱动说话动作。停止、静音、隐藏、免打扰取消会丢弃排队块和迟到结果，免打扰仍允许用户直接回复。

欢迎、戳一戳、摸头仍是上一版打包的离线 MP3，播放不会调用旧贝壳服务。待用户确认豆包声音后，再单独生成替换这三条固定素材。

`--self-test` 用模拟 WebSocket/音频检查协议字节样例、帧长/压缩/会话 ID、同一会话多段文字且输入结束前出声、结束/取消、PCM 限制、免打扰、鉴权失败清除凭证、断开与拒绝重定向。`--pcm-audio-check` 单独使用真实音频设备播放已打包的欢迎语。豆包真实延迟及账号权限仍需官方 Key 验证。

见 [豆包接入说明](../豆包TTS接入说明.md)。原 Harness 插件 v0.3.0 继续兼容，无需重装；旧 Mira 传输仅保留为回归/兼容代码，默认桌宠不会自动回退到它。

v0.4.1 已给安全输入框补上 ⌘V、⌘A 和 Paste 按钮，手动试听失败会弹出原因，分别提示 HTTP 401/403。一次真实固定短句实测完整结束：首包约 0.88 秒，播放器启动约 1.14 秒；不含 Harness 生成时间，也非声学起音测量。用户已确认恢复正常。

## 鲸鱼娘语音通话（插件 v0.4.3、桌宠 v0.4.9）

启用 `dsh-whale-voice` 后，DS Bot 的 **语音通话** 按钮会使用鲸鱼娘当前选择的豆包音色。先在运行 Harness 的电脑上打开新版桌宠，加载已有语音配置并开启 **Sound**，再在 DS Bot 中拨打。通话界面显示 **语音：鲸鱼娘**。识别仍使用 Harness **Voice Input**（须先准备好识别模型）或浏览器语音识别；回复复用当前 Bot 的聊天模型。DS Bot 无需再次填写 TTS Key。远程打开 DS Bot 时，音频也在 Harness 所在电脑播放。

通话会临时接管当前会话的语音，不修改桌宠原来的持久绑定。可见回复按短句进入现有 socket 和豆包流式管线，音量驱动已有说话动作，浏览器不再重复朗读。**最终回复输入结束且实际音频播完**即恢复聆听，不再等待聊天记录投影或语音连接关闭确认。字幕跟随朗读文本更新，通话状态每 250 毫秒轮询；工具步骤与句间停顿不视作整段完成。**暂停**会停止当前及缓存语音；**恢复聆听**等待新一句，不补播旧回复。**结束通话**停止语音并释放临时接管，不中止 Bot 本身的任务。通话期间其他会话的朗读和主动通知被抑制，结束后不补播；免打扰仍允许用户主动通话的回复。

每台 Harness 主机同时只允许一通鲸鱼娘通话。页面关闭或连接丢失时，15 秒租约到期后由定时检查释放。合成或连接失败会暂停并提示，不静默切回浏览器声音；只有没有安装鲸鱼娘插件路由时才保留原浏览器朗读。Key 仅在原生桌宠中使用；经过 Harness 认证的连接路由只传通话控制和状态，同用户 socket 传可见回复和播放状态。

更新后通过 Harness 插件管理器重载鲸鱼娘插件（或在其他任务允许时重启 Harness），并刷新 DS Bot 客户端。全程使用公开插件接口。自动验证使用模拟模型、识别器、桌宠和音频输出，尚不能证明真实麦克风识别质量、声学回声消除效果或付费接口延迟。


### 连接复用（插件 v0.4.3、桌宠 v0.4.9）

提交通话问题时提前建立豆包连接，与 Bot 生成回复重叠。连续多轮复用同一 WebSocket，每轮使用新的合成会话 ID。恢复监听仍由最终输入结束和实际音频播放完成决定，与连接关闭无关。播放结束后本地空闲上限为 120 秒，每两秒检查；通话状态轮询不会刷新这个期限。挂断、暂停、断开语音、换凭证/音色及合成中出错会释放连接。若服务端提前关闭空闲连接，下次提问重新建连，不自动重播已经说出一部分的回复。普通非通话朗读保留既有生命周期。

依据[官方双向流式协议](https://docs.volcengine.com/docs/DoubaoVoice/WebSocketBidirectionalStreaming-V3?lang=zh)。模拟检查覆盖问题提交时预连接、两轮共用一次连接、会话 ID 隔离、迟到包、空闲断线重连和超时释放。真实延迟节省尚未测量。


## 情绪表情（桌宠 v0.5.0）

通过 **⋯ → Expressions** 选择 **Shy（害羞）**、**Surprised（惊讶）**、**Sad（委屈）** 或 **Sleepy（困倦）**。这一版是手动预览，尚未让 Bot 自动识别、选择情绪。预览不会取消通话语音，也不调用 TTS。身体使用原始素材，仅更新边缘柔化的脸部区域；每种表情有 33 个已对齐过渡帧，另配小幅程序头部动作。

进入 0.75 秒，恢复 1 秒；害羞/委屈总时长 5.2 秒，惊讶 4.4 秒，困倦 6 秒。语音开始时可以请求恢复，但从进入开始至少保留 3 秒，确保能看清。连续点击沿用冷却和最新待播动作规则，没有额外添加语音样本。

`assets/emotions-v1/` 保存素材和原始生成提示词；`tools/build-emotions.swift` 离线生成对齐、遮罩及带眼睑约束的光流中间帧，逐帧检查脸部遮罩以外的原图和透明通道保持一致。`--export-emotions <目录>` 导出四个 GIF、语音打断样例、关键 PNG 和 `expressions.png` 对照图，并检查资源完整性、停留与恢复。

### 尾巴动作修正

当前尾巴画在完整人物图里。已移除待机、说话和摸头时右下区域的摆动拉伸，并固定尾巴所在网格；保留眨眼、呼吸和上方发梢动作。当前尾巴保持静态，真正的弹性摆尾需要独立尾巴图层及遮挡连接，或对齐后的完整人物连续帧。

### 独立分层尾巴（v0.5.3）

尾巴已从原人物图分离为身体后方的独立图层。尾根固定在裙摆下，尾身小角度转动，尾尖延迟跟随；只变形尾巴自己的网格。周期 4.8 秒，尾身/尾尖角度约 1.8/1.4 度，尾尖相位延迟约 0.42 秒。可见尾巴沿用原画，内置 imagegen 只补隐藏尾根。头发、衣服和腿不参与尾巴摆动。Idle Motion 开关会平滑启停；挥手仍用已有完整人物帧，切入前短暂收回摆动，结束后渐进恢复。

### 补全遮挡头发与表情停留（v0.5.3）
