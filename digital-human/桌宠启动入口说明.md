# Harness 桌宠启动入口：实现与验证

版本：语音插件 0.5.4，桌宠 0.6.2/build 21。

## 0.5.4：侧栏隐藏／显示切换

按钮依据同用户桌宠回传的 visible 与 visibilityProtocol 状态显示「隐藏鲸鱼娘」「显示鲸鱼娘」或「启动鲸鱼娘」。固定 desktop_toggle 操作由宿主选择隐藏、显示或启动，不接受任意可执行路径。对支持隐藏的新版桌宠，等待可见状态回传才确认操作；超时、传输失败和宿主关闭都会结束等待，快速重复点击合并为一次切换。旧桌宠未声明能力时只保留启动/显示。

原生 hide_companion 复用已有 hideWhale，停止播报、释放麦克风并结束通话；show_companion 恢复形象，不会自动开始通话。安装包为 dsh-whale-voice-0.5.4.tgz，桌宠为 0.6.2/build 21。44 项插件单元测试、界面/宿主集成与桌宠构建自检通过，使用模拟识别器和音频。

已通过当前 Harness 插件管理器安装并启用 0.5.4。退出空闲旧版桌宠后，由新版插件启动已构建的 0.6.2/build 21；真实按钮检测到新版隐藏能力。连续点击同一侧栏入口，实际状态先由「隐藏鲸鱼娘」/按下变为「显示鲸鱼娘」/未按下，再恢复「隐藏鲸鱼娘」/按下，收到原生可见状态确认，应用保持运行。验证后返回原会话，未重启 Harness、未开启麦克风、未调用模型或付费 TTS。原有左对齐样式未改动。

## 0.5.3：恢复 DS Bot 原来的左侧位置

0.5.2 将底部入口改为纵向排列后，没有指定横向对齐，Flex 默认拉伸让原本 justify-content:center 的 DS Bot 按钮占满整行，文字因而居中。0.5.3 在插件注入的公开插槽容器上补充 align-items:flex-start，使每个入口保留自然宽度并靠左；鲸鱼娘仍独占 DS Bot 上方一行。

42 项插件测试、生成客户端一致性和界面交互检查通过。已通过当前 Harness 插件管理器更新并启用 0.5.3，实际截图确认 DS Bot 恢复原来的左侧位置、与上方鲸鱼娘图标对齐；随后返回用户原来查看的会话。本次只修改布局样式，未重启 Harness。

## 用户操作

进入 Harness 后自动启动鲸鱼娘一次；左下角 DS Bot 上方提供「启动鲸鱼娘」/「显示鲸鱼娘」。退出后保持关闭，点击按钮可重开；隐藏后点击可显示。此入口不开麦、不拨号、不播放欢迎语，语音仍由双击形象触发。

## 激活

已通过当前已安装 Harness 的插件管理器，将旧版升级到 0.5.2 并启用，插件详情确认 0.5.2 和运行中。0.5.1 首次加载后发现底部容器横向排列；0.5.2 通过公开 data-slot 锚点改为竖向排列，实际截图确认启动/显示入口独占 DS Bot 上方的一行。

用户明确允许重开 Harness 后，使用既有历史版启动器正常退出并重开，保留原历史数据入口。安装一度因 Mac 锁屏暂停，用户手动解锁后已继续完成。桌宠现运行重新构建的 0.6.1/build 20。

实际操作确认：

- 先关闭桌宠，等待入口变为「启动鲸鱼娘」；保持 Harness 运行时桌宠没有自动重新出现。
- 正常重开 Harness 后，未点击桌宠应用或启动按钮，入口显示「正在启动鲸鱼娘…」，随后桌宠自行出现并完成连接。
- 通过桌宠菜单 Hide Whale 隐藏后，点击 Harness 的「显示鲸鱼娘」成功恢复形象。
- 通过桌宠 × 退出，等待入口恢复「启动鲸鱼娘」，点击后桌宠成功重新出现；入口随后恢复绿色运行状态。
- 验证中没有发起通话、开启麦克风或调用付费 TTS/聊天模型。原会话保留，侧栏最终恢复展开。
- 当前 macOS Harness 收起侧栏时会隐藏整个侧栏及底部入口；重新展开后按钮位置与状态正常。折叠图标形态的可访问性由模拟界面检查覆盖，不宣称实际隐藏侧栏时入口仍可见。

## 实现

- 使用公开 sidebar.footer.action 列表插槽，排序 -400，高于 DS Bot 的 -300；支持中英文、折叠侧栏、状态与错误提示。
- 经过 Harness 认证的 connection 路由只接受 desktop_state、desktop_start、desktop_autostart 三个固定动作，浏览器不能提交可执行路径。
- 插件使用固定 /usr/bin/open 与参数数组启动独立应用，不使用 shell、不创建登录启动项、不修改 Harness 源码或安装目录。
- 同一宿主的自动启动只尝试一次；状态轮询不启动应用。手动显示通过原有同用户 socket 发送 show_companion，正常启动使用 Launch Services 复用实例。
- 默认查找用户 Applications、系统 Applications、相邻源码桌宠与当前工作区路径；Cordis 插件配置支持绝对 companionPath 与 autoStart: false。
