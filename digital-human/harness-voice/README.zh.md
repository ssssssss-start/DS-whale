# 鲸鱼娘动态语音桥接

## 桌面直连语音通话（插件 0.5.0、桌宠 0.6.0）

双击鲸鱼娘即可开始或结束语音通话，无需打开聊天页面。Harness 需在后台运行，启用本插件，并配置好聊天模型及已准备完成的 Voice Input 识别器；桌宠需要麦克风权限、豆包语音和开启 Sound。有绑定时使用绑定会话；未绑定时通过公开 Session controller 创建并记住普通的 **Whale Voice Conversation**，与最小权限的提醒投递会话分开。绑定会话忙碌或不可用时明确失败。

桌宠只在聆听时采集麦克风，每句最多 20 秒，约 1.1 秒停顿后停止收音。16 kHz 单声道 PCM16 WAV 仅保留在内存，分块通过同用户 socket 传给公开 `speechController.transcribe`；识别文字才进入正常会话提示词。不依赖浏览器路由，不保存原始录音，不自动切换识别器或聊天模型。首次通话可能触发 macOS 麦克风授权；识别模型准备和聊天模型配置需事先完成，不会静默下载模型。

独立电话状态条跟随角色移动，缩小角色也保持可读：蓝色 **Connecting**、绿色 **Listening**、橙色 **Recognizing / Thinking**、青色 **Speaking**、红色 **Paused / Unavailable**。包含红色挂断按钮，聆听和思考还对应不同的轻微姿态。生成和工具执行期间显示思考，实际起播后显示说话；最终输入结束且音频播完后，经过短暂输出排空延迟才恢复聆听。Agent 身体上下文同步对应的通话与麦克风状态。

桌面通话可在菜单 **Pause Voice Call** / **Resume Voice Call** 暂停与恢复，再次双击或点击红色电话挂断。隐藏、静音、休眠或会话不活跃会释放麦克风，输入设备变更会暂停。迟到的权限结果、ASR 结果和旧通话状态不会重新开麦或发送识别文字；挂断不取消 Agent 任务。后端断开会本地超时停止，桌宠心跳丢失也会释放宿主租约。原有 DS Bot 浏览器通话仍可使用，与桌面通话共享单通话限制。

详见[桌面通话说明与验证](../桌面直连语音通话说明.md)。更新本仓库不会自动安装进运行中的 Harness。

## 听觉与数字身体（插件 0.4.4、桌宠 0.5.4）

通过公开 systemPrompt 接口，为绑定会话注入“鲸鱼娘是你的数字身体”的说明，保留 Bot 原有名字、职责与设定。鲸鱼娘通话临时取得身体控制权，挂断后归还绑定会话；其他会话没有身体身份，也不能控制它。

DS Bot 通话在提交识别结果前标明 ASR 输入，Agent 可以自然地表达“我听到了”。文字输入和来源未知的输入不会标成语音；模型没有收到原始音频、音高、语气或环境声音。需要同时更新并构建 DS Bot 客户端；旧客户端的输入来源保留为未知。

`whale_body` 的 `action: "status"` 返回实时连接、可用状态、输入来源和桌宠声明支持的动作。目前包含 `greeting`（挥手）、`poke`、`headpat`、`shy`、`surprised`、`sad`、`sleepy` 和 `idle`（恢复待机）。Agent 动作不播放固定台词，也不打断动态回复。已有互动未结束时返回 `busy`，不替换用户互动；桌宠隐藏、设备不活跃、版本不支持或断开时不能执行新动作。动作控制不要求 TTS Key，也不要求开启 Sound。

命令两秒后过期，必须收到匹配的桌宠回执。`accepted` 只表示动作已被接受，不保证动画已完成；超时、取消和控制权变更不算成功。未来增加动作，需要同步补充桌宠实现/能力列表和插件动作注册/工具参数。本实现不修改 Harness 或用户数据。更新本仓库不会自动安装到正在运行的 Harness。

在 Harness 的「插件 → 添加插件」中安装本目录，然后启用 `dsh-whale-voice`。通过公开 `session/event` 和 `agent/assistant-stream` 插件事件接入，无需修改 Harness。

桌宠 v0.4.3 可在 `desktop-preview/voice-config.local.json` 的 `doubao_api_key` 中填一次 Key，启动时自动读取；文件已加入 Git 忽略，仅当前用户读写。修改后点 **Reload Voice Config…** 即刻加载，无需重启。**Connect Doubao Voice…** 仍可临时连接，只在内存保留本次输入。无需启动本地语音服务。选择 **Test Voice (Uses API)** 试听一条由 API 账户计费的短句；成功后显示 `Doubao connected · streaming ready`。见 [接入说明](../../README.zh.md#构建与使用)。凭证不进入 Harness 插件。

在 Harness 里发送以下格式的消息即可发声：

```text
[whale] 用鲸鱼娘的口吻，分三句简短中文告诉我，今天你准备如何陪我工作。不要调用工具。
```

从 v0.2.3 起，已绑定会话中，你直接发送消息后产生的新回复会自动朗读，不需要 `[whale]`。未绑定会话仍可用该前缀请求单轮朗读。不会补播历史回复，也不把后台自动化、Bot 间通信、思考或代码块自动读出来。插件按完整句子发送，桌宠串行合成并缓冲最多两段就绪音频，播放当前句时准备下一句。音量驱动轻微说话和鲸尾动作，尚未实现音素嘴型同步。

菜单 **Stop Speaking**、静音、隐藏、点击角色互动、下一轮语音回复和取消生成都会停止本地播放并丢弃旧结果。取消本地请求不保证网页端立即停止合成。插件通过仅本机同用户可访问的 Unix socket 通信，目录权限 0700、socket 权限 0600，不开放浏览器可访问的端口。

v0.3.0 会把相邻短句合并到至少 18 个字符；从第一条短句起最多额外等待 180 毫秒，长句和回复结束时的余句立即发送，减少极短台词各自发起合成的开销。

桌宠 v0.4.0 将一轮回复的多个片段送入豆包官方 TTS 2.0 的同一个双向 WebSocket 会话，输入文字时同时接收 PCM 音频，预缓冲约 150 毫秒后起播，直到 Harness 本轮结束才结束语音会话。插件发送清理后的完整片段，并非逐原始 token 转发。不再创建网页对话、要求模型复述或使用网页凭证。旧 Mira 传输仅保留为兼容/回归代码，正常桌宠流程不会自动回退到它。

`/tmp/whale-voice-<uid>/latency-*.jsonl` 仅记录计时、字符数和缓存状态，不记录对话内容和凭证。计时从 Harness 发出用户消息事件开始，不含此前的界面/派发耗时；播放时间是播放器启动调用时间，未用麦克风测量声音实际传出时刻。`tts_start.overlaps_playback` 可验证并行准备下一句，`cache_hit` 区分缓存。新增记录流式首包、整段合成耗时、服务分阶段耗时与缓冲耗尽次数。记录增加提供商与固定样音/会话来源；固定样音不含真实 Harness 模型时间，WebSocket 整段合成耗时包含等待后续文字的时间。`mira-tts/bridge/timings/` 属于历史贝壳桥接记录，不是豆包计时。报告的 `estimated_gap_ms` 用连续播放启动时间减去上一句时长估算间隔；原始 `gap_ms` 只是完成回调后的交接开销，均未测量音频内置静音。

```sh
node --test digital-human/harness-voice/test/*.test.mjs
python3 digital-human/harness-voice/report.py --out digital-human/harness-voice/review
```

## 主动交互 v0.2

通过 Harness 插件管理器更新包，旧版 link 安装需重新安装以刷新依赖和模块缓存。新版桌宠选择 **Follow Next Conversation**，再在 Harness 目标会话发一条用户消息，即绑定该会话；**Stop Following** 取消关注。**Proactive Voice** 独立开启主动语音。

**Do Not Disturb** 支持 30 分钟、1 小时、持续开启；重启保留，立即取消主动播报并丢弃迟到音频，恢复不补播。直接 `[whale]` 对话仍可回应，全局 **Sound** 关闭则全部无声。安静时段默认本地时间 23:00–09:00；隐藏或设备不活跃时抑制主动语音。**Recent Messages** 查看未读文字、来源与交付状态。

**Companion Check-ins** 单独开启：与鲸鱼娘未互动 30 分钟、两次至少间隔 60 分钟、每天最多 3 次；无回应就等再次互动。首版用固定温和台词，不额外调用模型，不读取屏幕/键盘。

公开审批事件等待 2 秒后提醒一次，决定到来后撤销，不接管审批。普通轮次结束不播报任务成功。关注会话的 Agent 可先用 `whale_task_evidence`，再用 `whale_report_task` 引用本轮工具结果序号上报；文案明确归属 Agent 的声明，不替它担保验证成功。终止错误只称这一轮运行出错。

明确要求提醒时，让关注会话的 Agent 调用 `whale_create_reminder`，提供 `at`（带时区的 ISO 时间）或 `dailyTime`（HH:mm），`timeZone` 默认 Asia/Shanghai。插件通过公开 Session controller 创建最小工具范围的鲸鱼娘会话，用 Harness schedule 投递。`whale_manage_reminders` 只列出/删除本插件登记的提醒。安装不会创建定时任务；问题卡提醒和精确跳转原会话暂未实现。

偏好、去重及功能性未读文字通过公开 `storageDomain` 存入自己的 `whale_voice` 域，不读取 Harness 私有文件或凭证。桌宠设置用自身 UserDefaults。缺少公开接口时停用主动能力，原有手动语音独立保留，不修改 Harness。

宿主集成检查（模拟会话/调度适配器，使用真实公开存储 API）：

```sh
DSH_HARNESS=/absolute/path/to/deepseek-harness node --import /absolute/path/to/deepseek-harness/node_modules/tsx/dist/loader.mjs --import ./digital-human/harness-voice/test/harness-resolve.mjs digital-human/harness-voice/test/host.integration.mjs
```

测试解析器不发布，也不作为运行时依赖。

## 直接选择会话（v0.2.2）

使用更新后的 DS Bot 客户端，右键 Bot → **绑定鲸鱼娘**，即可直接绑定当前会话。通过 Harness 已认证的 connection 路由 `/api/whale-voice` 接收操作，使用公开 Session controller 列表校验会话，存入插件自己的存储域，不发送提示词、不启动智能体。更新后的桌宠菜单显示所选名称。切换时撤销旧会话未结束的任务通知，保留已有提醒，不开启语音；暂不支持群聊。原有 **Follow Next Conversation** 仍可使用。接口仅返回绑定信息，不返回对话内容或凭证。未来 Bot 开启新会话段后需要重新绑定。

## 绑定后直接朗读（v0.2.3）

绑定同时表示允许朗读该会话未来的直接回复；需要配置豆包并开启 Sound。Proactive Voice 和免打扰控制主动通知，你自己发送消息后的回复仍可回应。取消绑定或切换会话会停止旧会话尚未播完的自动回复，包括模型已经结束但播放器还在播的部分。历史回复不补播，后台定时消息和 Bot 间通信不进入这条自动朗读通道。填入 Key 后先显示 `Doubao key set · select Test Voice`；成功合成才显示 `Doubao connected · streaming ready`。绑定会话无需前缀。

## 鲸鱼娘语音通话（插件 v0.4.3、桌宠 v0.4.9）

启用 `dsh-whale-voice` 后，DS Bot 的 **语音通话** 按钮会使用鲸鱼娘当前选择的豆包音色。先在运行 Harness 的电脑上打开新版桌宠，加载已有语音配置并开启 **Sound**，再在 DS Bot 中拨打。通话界面显示 **语音：鲸鱼娘**。识别仍使用 Harness **Voice Input**（须先准备好识别模型）或浏览器语音识别；回复复用当前 Bot 的聊天模型。DS Bot 无需再次填写 TTS Key。远程打开 DS Bot 时，音频也在 Harness 所在电脑播放。

通话会临时接管当前会话的语音，不修改桌宠原来的持久绑定。可见回复按短句进入现有 socket 和豆包流式管线，音量驱动已有说话动作，浏览器不再重复朗读。**最终回复输入结束且实际音频播完**即恢复聆听，不再等待聊天记录投影或语音连接关闭确认。字幕跟随朗读文本更新，通话状态每 250 毫秒轮询；工具步骤与句间停顿不视作整段完成。**暂停**会停止当前及缓存语音；**恢复聆听**等待新一句，不补播旧回复。**结束通话**停止语音并释放临时接管，不中止 Bot 本身的任务。通话期间其他会话的朗读和主动通知被抑制，结束后不补播；免打扰仍允许用户主动通话的回复。

每台 Harness 主机同时只允许一通鲸鱼娘通话。页面关闭或连接丢失时，15 秒租约到期后由定时检查释放。合成或连接失败会暂停并提示，不静默切回浏览器声音；只有没有安装鲸鱼娘插件路由时才保留原浏览器朗读。Key 仅在原生桌宠中使用；经过 Harness 认证的连接路由只传通话控制和状态，同用户 socket 传可见回复和播放状态。

更新后通过 Harness 插件管理器重载鲸鱼娘插件（或在其他任务允许时重启 Harness），并刷新 DS Bot 客户端。全程使用公开插件接口。自动验证使用模拟模型、识别器、桌宠和音频输出，尚不能证明真实麦克风识别质量、声学回声消除效果或付费接口延迟。


### 连接复用（插件 v0.4.3、桌宠 v0.4.9）

提交通话问题时提前建立豆包连接，与 Bot 生成回复重叠。连续多轮复用同一 WebSocket，每轮使用新的合成会话 ID。恢复监听仍由最终输入结束和实际音频播放完成决定，与连接关闭无关。播放结束后本地空闲上限为 120 秒，每两秒检查；通话状态轮询不会刷新这个期限。挂断、暂停、断开语音、换凭证/音色及合成中出错会释放连接。若服务端提前关闭空闲连接，下次提问重新建连，不自动重播已经说出一部分的回复。普通非通话朗读保留既有生命周期。

依据[官方双向流式协议](https://docs.volcengine.com/docs/DoubaoVoice/WebSocketBidirectionalStreaming-V3?lang=zh)。模拟检查覆盖问题提交时预连接、两轮共用一次连接、会话 ID 隔离、迟到包、空闲断线重连和超时释放。真实延迟节省尚未测量。
